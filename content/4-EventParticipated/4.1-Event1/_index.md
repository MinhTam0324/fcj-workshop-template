# Event Summary Report: "Cloud Architect"

### Event Information
- Event name: Cloud Architect
- Format: Team-based competition
- Scale: 8 participating teams, each with 5 members
- Theme: Cloud computing and Cloud architecture design

### Event Objectives
- Gain a deeper understanding of the fundamentals of cloud computing.
- Build up knowledge of cloud architecture design patterns.
- Strengthen teamwork and communication skills.
- Enhance problem-solving thinking under time pressure.
- Get familiar with real-world competitive scenarios in cloud architecture design.

### Event Overview
The competition took place over multiple direct knockout rounds between pairs of teams. Two teams competed by answering a set of questions with increasing difficulty. The team with the higher score advanced to the next round. In the case of a tie, a tiebreaker question decided the winning team based on answer speed.

Each team could use two special skills during a match:
- Minimal Risk: If the answer is wrong, no points are deducted; if the answer is correct, only half the points of the question are awarded.
- Star of Hope: If the answer is correct, the score is doubled; if the answer is wrong, the points deducted are also doubled.

The questions covered many Cloud topics including cloud services, networking, storage, security, scalability, high availability, and system design principles.

### What I Learned
Through this event, I gained a better understanding of:
- Cloud computing concepts and today's cloud service models.
- Best practices for designing scalable and sustainably operating Cloud architectures.
- The importance of choosing the right cloud services based on the actual requirements of the system.
- The difficulty of real-world AWS certification exams.

### Personal Reflections
I found this event quite interesting during the internship, with creativity and innovation, giving everyone a chance to learn while keeping a relaxed spirit. It created a stronger connection within the AWS community.

Overall, this event was both dynamic and fun, creating a relaxed atmosphere and also helping me consolidate my cloud knowledge during my studies while getting a sense of the difficulty of the certification exams.

### Conclusion
The Cloud Architect event was organized very methodically, effectively combining knowledge learning with fun, friendly competition. The competition helped participating students systematize their cloud architecture concepts, train their analytical thinking, and strengthen team spirit.
