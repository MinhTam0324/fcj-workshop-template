### Week 7 Achievements:
- Understood the role of AWS SSO: centralized sign-in management across multiple AWS accounts in an Organization instead of creating separate IAM Users per account.
- Grasped advanced permission control mechanisms in IAM:
  - Permission Boundary: sets the maximum permission limit for a User/Role, even when policies grant broader access
  - Using Conditions to restrict Role transfer, reducing privilege escalation risks
- Learned that AWS Security Hub checks the account's security posture against security benchmarks and aggregates findings from multiple services in one place.
- Grasped how AWS WAF works: protecting web applications and APIs from common attacks using request filtering rules.
- Understood that AWS KMS is used to create and manage encryption keys, and how AWS services integrate with KMS for data encryption.
- Practiced basic labs on SSO, Security Hub, and KMS.
